# 时刻 Moment — Web C 端日子线 Spec

> 日期: 2026-08-17
> 状态: 样稿已与用户对齐（`docs/superpowers/mocks/c-end-feel.html`），本轮落地第一版
> 范围: 重做 `apps/web` 视觉与壳层主次；不改 API / dto / 权限 / 媒体语义
> 权威边界: 数据与权限听 `2026-08-15-moment-design.md`；功能面听 `2026-08-16-web-product.md`；视觉与壳层听本文（替换 `2026-08-16-web-redesign-sticker-design.md` 的视觉体系）。冲突时：契约听原文，功能听 web-product，观感听本文。

## 0. 它是什么

产品是家里几条会生长的**日子线**（链），不是相册。图、纯文字、视频、九宫格都是一等公民。多条链按发生时间织在「大家的日子」里，点进某条链只看这一根线。

样稿已确认：暖纸、果子结、按内容变形、三档屏幕。本轮按样稿实现。

**本轮必须保留（用户点名）：**

- 链设置页（分享 / 成员 / 资料 / 危险区），入口从链页 `···` 进，不删路由。
- 主题三态（跟随系统 / 浅 / 深），放在「我」里。
- 登录用户信息：昵称、邮箱；退出放在「我」或头像菜单，不放侧栏底。

**本轮明确不做、但壳层要让得下（后续时间线功能）：**

- 关闭 / 归档某条链、把它从长河藏起。
- 长河里按「开着的线」重织。现在每条时刻已标链名+链色，后续关线只是少织几根，不必再改卡片结构。
- 不做假的「关闭」按钮。

## 2. 壳层与三档屏幕

路由不增删。

**≥1400：** 左栏 168px（家，不是模块目录）+ 主列 + 右栏月份脊。左栏：字标、大家的日子、链名列表、开一条新的链；底是头像。不要「链」分类标题、不要退出、不要通知一级项。当前项只加字重，不用整条黄胶囊。

**900–1399：** 左栏收起。顶栏：字标 + 可横滑链胶囊 + 头像。月份进右上「N月」按钮 → 抽屉（沿用 TimelineRail 断点）。

**<900：** 同中屏，主列更贴边。不做手机底栏。

头像菜单：我、通知、退出。未读红点打在头像上。主题只在「我」。

大家的日子 = `/`（长河，多链按发生时间织在一起）。点链名 = `/chains/:id`（单线）。长河里用链色点+链名标出这条是哪根线。

## 3. 时间线

- 首页无「我的时间线」大标题，第一眼是 composer +「今天」。
- 日期头：今天 / 昨天 / N月D日；「今天」「昨天」走得意黑。结：今天大橘子、昨天中、更早小可可。
- `order=created_at`：线还在，日期结收起（发生日非单调）。
- 纯文字 = 软角气泡；有图/视频 = 媒体自己当底，不再套一层后台白卡。
- 1 张铺开 / 2–3 并排 / 4–9 宫格，规则沿用 web-product §4。
- 视频未播：16:9 + 中间动作色播放珠。
- 「0 条评论」不画。
- 卡片时间用人话（下午 3:23），不要 `2026-08-17 15:23`。
- 链页眉：链名 + 描述；不展示「创建者」。设置进 `···` →「这条链」。

右栏文案：标题「回到某个月」；开关「按记下的顺序看」。Feed 右栏不再放链筛选芯片（换线走导航）。链页仍有标签芯片。

## 4. 次级页

- **我：** 头像 + 昵称是主体；邮箱、主题三态、退出。可从这里进通知。
- **通知：** 空态写人话，不要光秃标题。
- **链设置：** 能力全留。分享做成「给长辈看这条链」。
- **发布：** 仍一个 modal。文案「记下此刻」/「记下」。

## 5. 非目标

不改 API、不改链为相册、不取消文本/视频/九宫格、不做关闭链 UI、不做手机底栏、不做公开广场。
