# 时刻 Moment — Web C 端商业化视觉体系

> 日期：2026-08-17；商业化收口修订：2026-08-18
> 状态：页面级方向已与用户通过前后对比稿逐项对齐；组件级规范待后续独立评审
> 范围：`apps/web` 的品牌基调、壳层、页眉、日子线、时刻内容、Tag、链来源、时间索引与响应式规则
> 权威边界：数据与权限听 `2026-08-15-moment-design.md`；功能面听 `2026-08-16-web-product.md`；链页眉成员与可见性听 `2026-08-18-chain-audience-header-design.md`；Web 视觉基础与页面组合听本文

本文是 Web 视觉的唯一真相源，整体替换 `2026-08-16-web-redesign-sticker-design.md` 的视觉规则，也替换本文修订前的“柔影卡片”表达。后续 Button、Modal、Menu、Field 等组件规范必须引用本文，不得另起一套颜色、密度或层级语言。

## 0. 产品命题

「时刻」是让家人共同记录日常的 C 端产品。它不是后台时间轴，不是照片管理器，也不是把每条内容装进白色卡片的信息流。

页面的单一任务是：**让用户轻松看见日子如何生长，并随手记下一刻。**

视觉命题固定为：

> 家庭记忆的温度 + 时间坐标的秩序。

页面只保留一个强识别元素：**日子线**。竖向线、日期结、时刻内容与月份索引共同表达“时间在延续”；其余元素保持安静。

## 1. 设计原则

### 1.1 C 端优先

- 信息有主次，不把每个动作做成等权功能入口。
- 质感来自比例、留白、色面、字级和边缘锚点，不来自大量边框、阴影或分割线。
- 文案从用户视角出发：记下、回应、大家的日子、回到某个月；避免“提交”“记录管理”等系统词。
- 内容优先于容器。图片、视频和正文是主体，组件外壳不得抢过内容。

### 1.2 清爽但不无趣

- 不用横线切割卡片内部，不用三等分操作栏，不用每项一个胶囊。
- 使用一处珊瑚动作色、一处淡紫日期色和链色点形成记忆，不让所有元素同时彩色。
- 同一页面最多一个高强调动作；其它操作保持低噪声。

### 1.3 一致来自隐形网格

- 作者行、正文、媒体、Tag、回应操作共用内容列左缘和右缘。
- `···` 固定在作者行右侧；表情锚定内容左缘；回应锚定内容右缘。
- 对齐依靠固定点击区域和内容边缘，不依靠可见分割线。

## 2. 基础视觉

### 2.1 色彩 Token

颜色必须落在 `apps/web/src/styles/tokens.css`，再由 Tailwind 映射。业务组件禁止写死色值。

| Token         | 浅色      | 深色      | 语义                                  |
| ------------- | --------- | --------- | ------------------------------------- |
| `--bg`        | `#f6f1ec` | `#171412` | 页面底，像自然光下的相纸              |
| `--surface`   | `#fffdfb` | `#26211e` | 输入、文字内容、面板                  |
| `--ink`       | `#2b201c` | `#f7efe9` | 主文字                                |
| `--muted`     | `#6f5d54` | `#c3b5ad` | 时间、说明、次级动作；普通小字满足 AA |
| `--line`      | `#d8c9c0` | `#463c37` | 必要边界；禁止当分割线滥用            |
| `--stroke`    | `#b79989` | `#76675f` | 日子线、圆环等时间结构                |
| `--action`    | `#c94a3a` | `#ff755e` | 记下、FAB、未读、主动作               |
| `--action-fg` | `#fffdfb` | `#241714` | 动作色上的文字                        |
| `--select`    | `#f2b84b` | `#f2b84b` | 选中月份、当前链的轻强调来源色        |
| `--select-fg` | `#2b201c` | `#2b201c` | 选中色上的文字                        |
| `--date`      | `#ded4ff` | `#433b5e` | 日期结、轻情绪入口                    |
| `--tag`       | `#4b7562` | `#87c2a5` | 正文内 Tag；两主题普通文字均满足 AA   |
| `--danger`    | `#b83a30` | `#ff8a72` | 删除、退出等危险动作                  |

链色点沿用确定性四色盘（粉 / 蓝 / 薄荷 / 紫），只用于链身份：导航点、汇总列表来源点、选链。链色不得替代动作色、状态色或 Tag 色。

浅色关键对比度基线：`muted/bg = 5.55:1`、`action/action-fg = 4.57:1`、`tag/bg = 4.65:1`。后续调色不得低于普通文字 `4.5:1`。

### 2.2 字体角色

- **品牌 / 固定日期词：** 得意黑 Smiley Sans。本地子集，只用于「时刻」「今天」「昨天」「记下此刻」等固定字形。
- **动态内容：** 系统黑体栈；链名、昵称、正文和动态 Tag 禁用得意黑。
- **数字：** 月份计数、时间可启用 `font-variant-numeric: tabular-nums`，字体仍继承正文栈。

| 角色       | 建议尺度         | 用途                     |
| ---------- | ---------------- | ------------------------ |
| Page title | 24 / 32，600     | 大家的日子、链名         |
| Day title  | 28 / 31，得意黑  | 今天、昨天               |
| Body       | 16 / 26，400     | 正文与正文内 Tag         |
| Meta       | 13 / 20，400–600 | 作者、时间、链来源、回应 |
| Caption    | 12 / 18，400     | 时间索引、辅助说明       |

字号必须通过语义角色复用；禁止继续扩散 `text-[13px]`、`text-[17px]` 等页面私有尺度。

### 2.3 间距与圆角

- 间距只使用 4 / 8 / 12 / 16 / 20 / 24 / 32px。
- 输入和内容色面使用 14–20px 圆角；情绪入口和主动作可用满圆。
- 同一时刻内部用 4–12px 的紧节奏；时刻之间用 20–24px；日期章节之间用 32px。
- 圆角只表达材质和触感，不给每段文字单独套胶囊。

### 2.4 深度与阴影

内容层默认**无阴影**：时刻、正文色面、媒体、日期结、选中导航、Tag、月份项均不得加卡片阴影。

阴影只允许表达真实浮层关系：

- Modal / Dialog / Sheet
- Popover / Menu / Tooltip
- 悬浮 FAB

具体阴影几何由相应组件规范定义。页面内容不得自行发明 `shadow-*`。

## 3. 壳层与三档布局

路由不增删。

### 3.1 宽屏（≥1400px）

工作区使用相邻三列，而不是把右栏贴到视口最右：

```text
[ 左栏 208 ]   [ 日子线 760 ]  32  [ 时间索引 184 ]
```

- 左栏：字标、大家的日子、链列表、开一条新的链；底部头像。
- 主列与时间索引组成一个整体工作区，在左栏后的可用空间中居中。
- 右栏必须紧邻主列，禁止与内容隔出数百像素空白。
- 当前导航使用轻色面与字重；不使用厚描边、偏移影或整条高饱和胶囊。

### 3.2 中屏（900–1399px）

- 左栏收起为顶栏：字标 + 可横滑链入口 + 头像。
- 主列最大 760px，居中。
- 时间索引进入页眉右侧月份入口，打开 Sheet；月份入口不得单独占一整行把页标题向下推。

### 3.3 小屏（<900px）

- 延续中屏顶栏，不新增底部导航。
- 日子线缩进减小；正文内容列不得被头像与时间线吃掉过多宽度。
- 可见控件保持轻巧，但点击区域至少 44×44px。
- 作者元信息拥挤时允许链来源换到作者行下方；Tag 仍与正文保持同一文本流。

实施本布局时，必须同步更新 `tokens.css`、Tailwind 映射和 `.claude/rules/web-ui.md`，让代码约束与本 Spec 一致。

## 4. 页面页眉

### 4.1 大家的日子

汇总页可以显示简短身份信息：

```text
[多链标] 大家的日子                         [记下此刻]
          来自 N 条时光链
```

- 不使用后台式“大标题 + 数据统计卡”。
- `N` 只解释当前内容来源，不承担运营指标语义。
- 主动作只有「记下此刻」。

### 4.2 单链页

链页眉遵循 `2026-08-18-chain-audience-header-design.md`：链名右侧是成员头像簇与可见性，`···` 固定在页眉最右，简介在下一行。

本文补充视觉约束：头像、可见性和 `···` 不加阴影；成员信息是链身份的一部分，不做成后台状态栏。

## 5. 日子线

- 日子线是全站视觉签名：竖向时间线 + 日期结 + 内容节点。
- 线使用 `--stroke` 的低强度虚线；不得额外增加横向分隔线。
- 「今天」使用动作色大结；「昨天」使用中等结；更早日期使用小结。
- 日期标题与线连接，但不画厚重卡片。当前日期可使用淡紫色面，禁止阴影。
- `order=created_at` 时线保留、日期结收起，保持发生时间非单调的约定。
- 发布入口挂在日子线起点；向下滚动后由 FAB 接力。

## 6. 时刻内容模式

一条时刻不是完整白卡，而是一组共享边缘的内容：

```text
[头像]  作者  时间  [链色点 链名]                       ···
        #Tag #Tag 正文从这里继续
        [媒体 / 文字色面]
        [情绪入口]                                [回应数]
```

### 6.1 基本结构

- `[头像 32] + gap 12 + [内容列]`。
- 作者、时间、链来源共用 Meta 角色；作者使用 600，其余使用 muted。
- `···` 固定在作者行右缘；视觉符号 16px，桌面点击区至少 40px，小屏至少 44px。
- 有媒体时媒体自己当底，不再外套卡片。
- 纯文字使用轻微 `--surface` 色面；无边框、无阴影。
- 媒体可有 1px 必要边界以处理浅色图片，但禁止厚描边和投影。

### 6.2 Tag 与正文

Tag 是内容语义，不是筛选按钮，也不是卡片尾部元数据。

- 有正文时：Tag 直接放在正文开头，与正文处于**同一文本流、同一字号、同一行**。
- Tag 使用 `--tag`，正文使用 `--ink`；只靠颜色和 `#` 前缀区分，不画胶囊、边框或底色。
- 多个 Tag 之间 6–8px；Tag 与正文之间 8px。
- 内容变长时与正文一起自然换行，禁止强制 Tag 单独占一行。
- 只有媒体、正文为空时：Tag 紧贴媒体之前渲染为一段文本；这是无正文情况下的自然降级。
- 所有已绑定 Tag 直接渲染，不在卡片里另做展开按钮。

示例：

```text
#海边 #周末 周末去看了海
```

### 6.3 汇总列表中的链来源

只在「大家的日子」等多链汇总列表中显示：

```text
simon  晚上 10:01  ● 周末小家                         ···
```

- 形式固定为 `链色点 + 链名`，放在作者时间行中。
- 链名可点击进入单链页；颜色点只表达身份，不表达状态。
- 单链页、分享页已知链上下文时隐藏，避免重复。
- 小屏空间不足时，链来源可换到同一元信息组的下一行；`···` 仍固定右侧。

### 6.4 情绪、回应与更多操作

三个动作不得等分，不画操作栏，不加横线或竖线。

- **情绪入口：** 内容左下的小圆形轻色面，表达最常用、最轻的互动；视觉 30–32px，点击区满足 40/44px。
- **回应：** 内容右下的气泡图标 + `N 条回应`；`0 条回应` 仍显示，确保入口位置稳定。
- **更多：** 回到作者行右侧，只给有权限的用户；不与情绪、回应排成第三列。
- 三者通过左缘、右缘与作者行边缘对齐获得秩序，不使用可见分割结构。

## 7. 时间索引

时间索引是阅读辅助，不是后台筛选器。

### 7.1 跨年结构

采用“年份是章节、月份是入口”：

```text
时间索引

2026                                  今年
  8月                                    2
  7月                                   18
  6月                                    7

2025
 12月                                    6
 11月                                    3

2024                                      ›
```

- 今年与当前查看年份展开月份。
- 其它年份折叠为一行；点击后只展开一个历史年份。
- 跨年依靠字级与 12–16px 留白表达，禁止横向分隔线。
- 当前月份使用 `--select` 的低比例混合色面；无阴影、无厚边框。
- 月份计数右对齐并使用等宽数字，只说明该月内容量。

### 7.2 中小屏

- 相同结构进入时间索引 Sheet，不另写一套数据或文案。
- 入口显示当前月份，如「8月」；打开后再展示年份层级。
- 切换「按记下的顺序看」时清日期锚定，规则沿用既有功能 Spec。

## 8. 状态、动效与无障碍

- 普通文本对比度最低 `4.5:1`；大字最低 `3:1`。
- 桌面核心操作点击区至少 40px；触控环境至少 44px。
- 所有可交互元素必须有 `focus-visible`；焦点环使用动作色，不靠阴影表达。
- 动效使用 160–220ms ease，只服务状态变化：发布后内容长出、Modal 进入、Popover 展开。
- `prefers-reduced-motion` 下将动效降至近零。
- Hover 不能承载唯一信息；头像、链来源、Tag、时间索引在触控下必须可理解。
- 深色主题保持相同层级关系，不将所有 surface 压成同一块黑色。

## 9. 工程沉淀规则

设计体系的落地顺序固定为：

```text
tokens.css → Tailwind 语义映射 → ui 基础组件 → 页面组合模式
```

- 禁止页面直接写十六进制颜色。
- 禁止新增一次性字号、圆角、阴影和控件高度。
- 页面组件只组合语义组件，不重复拼 Button、Menu、Modal 的内部状态样式。
- 组件必须覆盖 default / hover / pressed / focus / disabled / loading；选中类组件再覆盖 selected。
- 视觉验收至少覆盖 390 / 1024 / 1440 / 1895px，以及浅色 / 深色。
- 页面级截图回归必须包含：大家的日子、单链页、纯文字时刻、单图时刻、跨年索引、长 Tag、长链名。

当前不新建独立设计系统包；组件继续放在 `apps/web/src/ui/`，业务组合留在对应目录。稳定后再评估独立组件展厅或 Storybook。

## 10. 功能边界

- 不改 API、DTO、权限、媒体、分享和日期锚定语义。
- 图片、纯文字、视频与九宫格继续是一等内容，不把链改成相册。
- 链设置页及分享 / 成员 / 资料 / 危险区完整保留，入口仍从链页 `···` 进入。
- 主题保留跟随系统 / 浅 / 深三态，入口放在「我」。
- 昵称、邮箱、通知和退出继续由「我」或头像菜单承载；退出不放左栏一级位置。
- 汇总页的链切换继续走左栏 / 顶栏导航，时间索引不增加后台式链筛选器。
- 单链页可以在时间索引上下文中提供 Tag 筛选，但其样式不得复用正文内 Tag；筛选控件归后续组件规范。
- 不新增关闭 / 归档链 UI、不做手机底栏、不做公开广场、不做假的功能入口。

## 11. 下一阶段组件规范

组件规范按以下顺序逐个评审，不在本文提前锁死细节：

1. **Button**：语义层级、尺寸、图标、文案、全状态、危险操作。
2. **Modal / Dialog / Sheet**：层级、宽度、移动端形态、遮罩、焦点、关闭与操作区。
3. **Field**：输入、文本域、日期时间、校验、帮助与错误。
4. **Menu / Popover / Tooltip**：锚点、展开方向、触控降级、键盘行为。
5. **Feedback**：Banner、Toast、Empty、Skeleton、Confirm。

每份组件规范必须给出：适用场景、禁止场景、解剖结构、Token、尺寸、状态矩阵、响应式、无障碍、文案规则和视觉验收样例。

## 12. 页面级验收清单

1. 宽屏下时间索引紧邻主列，不贴视口最右。
2. 页面内容没有用阴影或横线堆叠层级。
3. 作者、正文、媒体、操作共用内容列边缘。
4. Tag 与正文同一文本流；正文为空时紧贴媒体之前。
5. 汇总页显示链色点与链名；单链页不重复显示。
6. 情绪入口在左、回应在右、更多在作者行；不存在三等分操作栏。
7. 跨年索引以年份章节表达；历史年份可折叠；没有分割线。
8. 浅色普通小字与动作按钮达到 AA；深色层级不糊成一片。
9. 390px 下点击区域、正文宽度、长链名和长 Tag 均可用。
10. Modal、Button 等页面引用组件遵循后续组件规范，不在页面内私自变体。
