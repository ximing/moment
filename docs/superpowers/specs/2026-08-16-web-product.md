# 时刻 Moment — Web 产品 Spec

> 日期：2026-08-16
> 状态：已通过对话评审，待实现计划
> 范围：重写 `apps/web`，做成真实家庭能日常使用的平板/电脑产品
> 权威边界：数据模型、API、权限、媒体、分享语义以 `docs/superpowers/specs/2026-08-15-moment-design.md` 为准。本文只定义 **Web 产品面**。禁止为本文改 dto 字段名或既有 HTTP 契约。

## 1. 目标与非目标

**目标：** 两位家长在平板或电脑上对等记录、回看；长辈用只读分享链接翻相册。功能已在后端齐备，本轮把交互做成可给家里人用的产品，而不是 API 后台。

**成功标准（家庭能用）：**

1. 未选链也能从「我的时间线」记下此刻（先选链再写）。
2. 时间线卡片上可点表情、可展开/进入评论，不必先点「详情」。
3. owner 能在链设置里生成、复制、吊销分享链接；无痕打开可见相册；吊销后公开页关闭。
4. 错误与角色展示为人话，界面不出现 `CHAIN_ROLE_INSUFFICIENT` 等机器码。
5. 1280px 桌面与 900px 平板主路径不撑破、不出现手机底栏。

**非目标（本轮明确不做）：** 获客落地页、PWA、找回密码、邮箱验证、公开广场、计费/多租户、手机底栏导航、Expo App 重做、独立设计系统仓库/Storybook、那年今日/PDF/HLS、分享访问统计、分享页申请加入。

## 2. 用户与场景

| 人 | 怎么用 Web |
|---|---|
| 记录的父母 | 打开就是「我的时间线」+「记下此刻」；图文视频、补记、打标 |
| 另一位家长 | 同等权限（editor/owner）；评论、表情、一起翻大图 |
| 长辈 | 不登录；打开 `/share/:token` 只读相册 |

链（如「宝宝成长」）是这个家的大本营：成员、邀请、分享都在链设置。feed 是各链汇总，不是替代链。

## 3. 信息架构

**空间：左栏是家，中间是此刻，右侧按需出现。**

| 区域 | 宽度 | 职责 |
|---|---|---|
| 左栏 | 固定 240px | 「时刻」字标；「我的时间线」；我参与的链（名 + 可选新动态点）；底：通知、我的资料。当前项高亮。 |
| 主栏 | 其余宽度 | 默认大图时间线。进入某链后换成该链时间线 + 链眉。设置与资料是主栏子页。 |
| 发布 | 主栏覆盖层 | 右上「记下此刻」。不占用独立列表路由。 |

**路由：**

| 路径 | 壳 | 含义 |
|---|---|---|
| `/` | Shell | 我的时间线（全部参与链） |
| `/chains/:id` | Shell | 该链时间线 |
| `/chains/:id/settings` | Shell | 链设置（分享 / 成员 / 资料 / 危险区） |
| `/moments/:id` | Shell | 单条时刻（评论主场） |
| `/notifications` | Shell | 通知列表 |
| `/me` | Shell | 我的资料：只读展示昵称与邮箱。`GET /me` 已有；`PATCH /me` 与头像 **尚未落地**，本轮不做改名/换头，避免发明 API |
| `/share/:token` | 无壳 | 长辈只读相册 |
| `/login` `/register` | AuthScreen | 同一套纸感 |
| `/invites/:token` | AuthScreen 或短流程 | 未登录先登录/注册，成功后进入该链时间线 |
| `*` | 视登录态 | 已登录：主栏「没有这个页面」；未登录：去登录 |

删除独立路由 `/chains/:id/compose`。深链到旧 compose URL 时 302 到 `/chains/:id` 并打开发布面板。

**权限在壳上的表现：**

- viewer：隐藏「记下此刻」；设置里只能看成员，不能生成分享、不能改资料/危险区。
- editor：可发布、可邀请；不能生成分享、不能改角色/转让/删链。
- owner：设置全开。

## 4. 时间线

主栏是按 `happened_at` 倒序的大图时间线，复用 `GET /feed` 与 `GET /chains/:id/moments`。

**一张时刻（MomentSheet）：** 作者头像（无头像则昵称首字）、昵称、发生时间（`format` 使用 `happened_at` + `happened_tz_offset`，文案「当时当地」）、补发轻标记、正文、媒体、标签、表情条、评论数。

**媒体：**

- 1 张：铺满主栏内容宽（最大宽度 720px）。
- 2–3 张：等分并排。
- 4–9 张：宫格。
- 点击进入灯箱：深墨底、左右键/点击两侧切换、Esc 关闭。视频在卡片与灯箱均可播。

**互动：**

- 表情：卡片上点选 `REACTION_EMOJIS`；再点同一枚则 `DELETE` 取消。
- 评论：点评论数展开该卡下方预览（最新若干条 + 「查看全部」进 `/moments/:id`），或直接进详情。详情页是评论主场（输入框、删除自己的评论）。
- 自己的时刻：卡片菜单「编辑」「删除」。编辑打开发布面板的编辑态（正文/时间/标签；媒体本轮不支持改已发布附件）。删除二次确认。
- 禁止编辑他人时刻。

**筛选：**

- `/`：全部链，无标签条。
- `/chains/:id`：已是单链；标签为单选芯片（与现 API `tag_id` 单值一致），可清空。
- 「按添加时间看补发」放在筛选菜单，默认关闭（`order=happened_at`）。第一屏不放双态大开关。

**分页：** 无限滚动，`limit: 50`，游标与现客户端一致。底部哨兵 + 失败横幅「没法加载更多，点重试」。

**空态：**

| 条件 | 主文案 | 主按钮 |
|---|---|---|
| 一条链都没有 | 建第一条时光链，比如「宝宝成长」 | 创建链（左栏或主栏对话框） |
| 有链、当前视图无时刻 | 还没有记下任何一刻 | 记下此刻 |
| 标签/排序筛空 | 没有符合条件的时刻 | 清除筛选 |

**加载：** 首屏骨架（三张纸）。整页失败：横幅 + 重试，左栏仍在。

## 5. 发布

入口：壳右上「记下此刻」。在链页默认 `chainId` 为当前链；在 `/` 先选链（大块点击链名，禁止下拉搜 UUID）。

形态：主栏居中大面板（遮罩），不是新路由。viewer 不渲染入口。

**用户不选 type。** 实现映射：

| 用户操作 | `type` |
|---|---|
| 只有文字 | `text` |
| 1–9 张图（可附文字） | `media` |
| 恰好 1 个视频（可附文字） | `video` |

图和视频互斥：已选图再选视频需确认替换，反之亦然。

**面板顺序：**

1. 大文本框，占位「这一刻…」。
2. 媒体：点击或拖拽；宫格预览可删单张。Web 端压缩后再走现有 `uploadMedia`（图：最长边 2048、质量与 App 对齐 0.85；视频：超限当场拒绝，本轮不做转码）。进度按文件；可取消未完成上传。
3. 「就是现在」为默认。展开「这是补记」后才出现本地日期时间与 `isBackfill=true`。
4. 标签：本链芯片多选；editor+ 可输入新建（`POST /chains/:id/tags`）。

**校验（人话，提交前）：** 文字类型正文必填；图 1–9 且单张 ≤10MB；视频恰好 1 且 ≤500MB、时长 ≤300s；标签数遵循 dto。

**提交：** 面板不关，主按钮显示进度。成功：关面板、invalidate `feed` / 该链 moments / tags；时间线按 `happened_at` 出现（可乐观插入，失败则回滚并留上面板稿）。失败：面板保留全部已填内容。

**编辑态：** 只 PATCH 正文/时间/标签/补发；不重传媒体。

## 6. 链大本营与分享

### 链页 `/chains/:id`

链眉：封面（空则名称首字）、名称、简介、角色人话（创建者 / 可记录 / 只看）。右侧：有权则「记下此刻」；「设置」进 settings。主栏其余为该链时间线。

左栏高亮该链。不设「时间线 / 成员 / 邀请 / 标签」平级 tab。

### 设置 `/chains/:id/settings`

左目录 + 右内容。目录项：分享、成员、资料、危险区。无权限的项不显示（viewer 只见「成员」只读）。

**分享（owner）：**

- 「生成分享链接」：默认永不过期；可选 7 天 / 30 天 / 指定日期（`expiresAt` ISO）。
- 列表每行：创建时间、到期、状态（有效 / 已吊销 / 已过期）、复制、吊销。
- 复制：写入 `origin + '/share/' + token`，成功给予短暂「已复制」。
- 吊销二次确认文案：「长辈将立刻打不开这本相册。」确认后 `DELETE /share-links/:id`。
- 一链多链接。editor/viewer 不渲染本块。

**成员：** 头像/首字、昵称、角色。owner：改 editor↔viewer、移除、转让（确认框输入链名）。owner 退链前必须转让。邀请：生成链接或填邮箱；复制文案「把这串发给要一起记的人」；未接受的可吊销。

**资料（owner）：** 改名、简介（`PATCH /chains/:id` 的 `name` / `description`）。封面：`updateChainInputSchema` **不含** `coverMediaId`，本轮不提供换封面控件，链眉空封面用名称首字。`visibility` 不提供 public 开关；保持私密 + 分享链接。

**危险区（owner）：** 删除链，输入链名确认。

**标签：** 资料页底部轻量列表：展示、删除、新建。日常打标只在发布面板。

### 分享相册 `/share/:token`

无壳。链名、简介、副文案「只读分享 · 时刻」。同一套大图时间线：无表情按钮、无评论输入；可显示只读计数。媒体 URL 带 `?st=`。灯箱可用。

| 状态 | 整页文案 |
|---|---|
| 有效 | 相册 |
| 未知 / 吊销 / 过期 | 这本相册的分享已关闭 |

页脚一行小字：「由家庭用「时刻」记录」。不做登录条、不做申请加入。

### 邀请 `/invites/:token`

纸感短页。未登录：登录或注册，成功后自动 accept。已登录：一键加入。成功进 `/chains/:id`。失败人话（链接无效、已用过、过期）。

## 7. 视觉

气质：纸上的家庭相册。晚上两人对着屏幕翻，安静、图大、字少。

**Token（实现落在 `apps/web/src/styles/tokens.css`，名称固定）：**

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F6F1E8` | 页面底 |
| `--ink` | `#1C1916` | 主文字 |
| `--ink-muted` | `#6B635B` | 次要文字 |
| `--accent` | `#2F4F4A` | 主按钮、左栏当前项 |
| `--accent-fg` | `#F6F1E8` | 主按钮字 |
| `--line` | `#E4DCD0` | 分割与描边 |
| `--danger` | `#8F2D2D` | 危险操作 |
| `--shadow` | `0 1px 2px rgba(28,25,22,.06)` | 卡片 |
| `--radius` | `10px` | 卡片与按钮 |
| `--content` | `720px` | 主栏内容最大宽 |

标题：高对比中文标题（优先 `"Source Han Serif SC", "Noto Serif SC", "Songti SC", serif`，加载失败回退系统衬线）。正文：系统黑体 16–18px，行高 1.6。

动效：面板/灯箱/复制提示 150–250ms ease；禁止弹跳与装饰性大动效库。

登录、注册、邀请、分享与已登录壳共用上述 token，禁止第二套灰黑皮肤。

## 8. 组件与数据

**保留：** `@moment/dto`、`@moment/api-client`、`tokenStore` / `moment:auth-cleared`、TanStack Query、现有上传 `uploadMedia`。

**替换：** 全部 page、`AppShell`、`MomentCard`、链上四 tab 面板的交互结构（逻辑可迁入新组件）。

**新建单元（一名一事）：**

- `Shell` — 左栏 + 主栏 + 「记下此刻」
- `Timeline` — 无限滚动、空态、错误横幅
- `MomentSheet` — 单张纸
- `Lightbox`
- `ComposePanel`
- `ChainHeader` / `ChainSettings`
- `ShareAlbum`
- `AuthScreen`
- `tokens.css` + `Button` `Field` `Banner` `Confirm`

禁止新全局 store。Query key 继续集中在 `src/api/keys.ts`。发布/评论/表情成功后 invalidate feed、该链 moments、该 moment、tags、通知（若影响未读）。

创建链：左栏底或空态打开对话框（名必填、简介可选），成功后进入 `/chains/:id`。

## 9. 错误映射（展示层）

实现一张表，未列出的码回退「出了点问题，请重试」。日志仍打原码。

| 码 | 用户文案 |
|---|---|
| `UNAUTHORIZED` / 401 | 登录过期了，请重新登录 |
| `CHAIN_NOT_FOUND` | 看不到这条链，或它已经不在了 |
| `CHAIN_ROLE_INSUFFICIENT` | 没有权限做这件事 |
| `SHARE_NOT_FOUND` | 这本相册的分享已关闭 |
| `SHARE_LINK_NOT_FOUND` | 这条分享链接不存在 |
| `MEDIA_NOT_FOUND` | 看不到这张图或视频 |
| `MEDIA_TOO_LARGE` | 文件太大 |
| `VALIDATION_ERROR` | 有些内容需要改一改 |
| `RATE_LIMITED` | 操作太频繁，请稍后再试 |
| `OWNER_MUST_TRANSFER` | 创建者离开前需要先把链交给别人 |
| `CANNOT_TRANSFER_TO_SELF` | 不能转让给自己 |
| `CANNOT_CHANGE_OWN_ROLE` | 不能改自己的角色 |
| `MEMBER_NOT_FOUND` | 这个人已经不在链里 |
| `TAG_NOT_IN_CHAIN` | 这个标签不属于这条链 |
| `NETWORK_ERROR` | 网络不太好，请重试 |

401：清 token 与 query，跳转 `/login`，带 `state.from`。

## 10. 测试与验收

**手测清单（实现完成必须逐项勾）：**

1. 注册 → 创建「宝宝成长」→ 记下纯文字「此刻」。
2. 同一链记下 1 张图、记下 1 段视频；灯箱可开可关。
3. 第二账号以 editor 加入 → 在时间线卡片上点表情、发评论。
4. owner 生成永不过期分享 → 复制 → 无痕窗口打开相册看见图文。
5. 吊销该链接 → 无痕刷新 → 「这本相册的分享已关闭」；媒体 `?st=` 旧 token 不可见。
6. 再开一条 7 天链接，列表状态正确。
7. viewer 看不到「记下此刻」和分享生成。
8. 1280px 与 900px 走完 1–4，左栏+主栏不横向撑破。
9. 断网点发布：面板稿还在，人话错误。
10. 邀请链接：未登录注册后落入该链。

**回归：** `pnpm --filter @moment/dto test`、`@moment/api-client test`、`@moment/server` 相关测试保持绿。本轮允许不写 web 组件单测与 e2e 框架。

## 11. 实施顺序

1. tokens + Shell + AuthScreen（登录/注册换肤并可进空时间线）
2. Timeline + MomentSheet + Lightbox + 卡片表情/评论入口
3. ComposePanel（含选链、压缩、补记、标签）
4. ChainHeader + ChainSettings（分享优先，然后成员/资料/危险区）
5. ShareAlbum + 邀请页
6. `/me` 只读页 + 手测清单收口

每步可独立提交。不改 `packages/dto` 字段名；不改 server 路由语义；不新增 `PATCH /me`、不扩展 `coverMediaId`。需要改资料或封面时另立项。

## 12. 与原 spec 的关系

`2026-08-15-moment-design.md` 仍是后端与权限的唯一权威。本文补上原文未写的 Web 产品面。冲突时：契约听原文，交互听本文。原文 §12 backlog 中的「分享链接访问统计」等仍属增长功能，不在本轮。
